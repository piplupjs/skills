## Use Mobbin for Flows and Screen Layouts

**Impact: HIGH (screens follow how shipped apps solve the flow)**

[Mobbin](https://mobbin.com) is a library of screenshots and recorded flows from real web and mobile apps, searchable by screen type (onboarding, paywall, settings, checkout) and UI element. Use it for product surfaces: how many steps a flow has, where actions sit, what each state looks like.

Mobbin needs a signed-in account for most content. The agent cannot sign in for the user, so:

1. If browsing is available and the user is already signed in, search by screen or flow name and summarise the pattern.
2. Otherwise, ask the user to share 2–3 screenshots or links, and say which screen type to search for.
3. If neither is possible, name the pattern from well-known apps and say it was not checked against references.

Compare several apps and take the pattern they share; don't clone one app.

Reference: [Mobbin](https://mobbin.com)
