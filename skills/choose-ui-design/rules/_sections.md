# Sections

This file defines all sections, their ordering, impact levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Context (context)

**Impact:** CRITICAL  
**Description:** What the project already has and what kind of surface is being built. A source that fights the stack or suits the wrong surface is wasted work.

## 2. Inspiration (inspire)

**Impact:** HIGH  
**Description:** Looking at how real products solve the same screen before designing it, so the result follows proven patterns instead of a generic default.

## 3. Sourcing (source)

**Impact:** HIGH  
**Description:** Which resource supplies each layer of the UI: base primitives, page sections, effects, layouts, and backgrounds.

## 4. Fit (fit)

**Impact:** MEDIUM  
**Description:** Making sourced pieces belong to the project: tokens and motion restraint.
