## Use Kargul's Swipe File for Product Details

**Impact: HIGH (details that make UI feel finished)**

[Kargul's swipe file](https://kargul.studio/swipe-file) is a curated collection of product design moments from modern SaaS: empty states, toasts, command menus, onboarding checklists, pricing toggles, settings rows. Use it when the layout is settled and the screen still looks like a template.

Look for one detail per screen and add it deliberately:

- an empty state with an illustration-free, action-first message
- a keyboard hint next to the primary action
- inline confirmation instead of a modal
- a subtle count, badge, or progress cue

Take the idea, rebuild it with the project's primitives and tokens.

Reference: [Kargul swipe file](https://kargul.studio/swipe-file)
