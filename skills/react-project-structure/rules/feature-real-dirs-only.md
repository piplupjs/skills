## Create Only Directories with a Real Responsibility

**Impact: HIGH (no empty scaffolding to maintain)**

Create a page area or role folder only when it has files with a real job. A list-only domain gets `list/` and no `details/`; an area with no static config gets no `config/`. Do not scaffold empty folders for symmetry.
