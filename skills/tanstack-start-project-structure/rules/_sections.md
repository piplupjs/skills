# Sections

This file defines all sections, their ordering, impact levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Routes (routes)

**Impact:** CRITICAL  
**Description:** How the file route tree is shaped and what a route file may contain.

## 2. Data Loading (loader)

**Impact:** HIGH  
**Description:** How loaders, queries, and loading/error views connect, so loader failures and pending navigation reach the feature views.

## 3. App Wiring (app)

**Impact:** MEDIUM  
**Description:** Where the router, start entry, configuration, and generated route tree live.
